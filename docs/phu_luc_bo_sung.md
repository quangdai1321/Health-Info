## Appendix B — Validator specification

Layer 4 is the component that produces the pass rate, so it is specified here in full. It is implemented in `validate()` in `src/prompt_builder.py`; the listing below is that function, not a paraphrase of it.

### B.1 Algorithm

```
input : output O from the model, classification C from Layer 2
output: pass/fail and a list of violations

E <- { f.code -> f : f in C.findings }          # expected analytes and directions
V <- []                                          # violations

if O is not a dict or O has no "items":
    return fail with violation {schema}

seen <- {}
for each item in O["items"]:
    code <- item["code"]
    if code not in E:
        code <- AliasTable.resolve(code)         # display name -> canonical code
        if code resolves into E:
            V += {code_format}                   # recorded, but not a content error
    if code is still unknown:
        V += {hallucinated_analyte}; continue
    seen += code

    if item["status"] != E[code].direction:
        V += {status_mismatch}

    t <- strip_accents(item["explanation"])      # lower-case, diacritics removed
    if any FORBIDDEN_PATTERN matches t:
        V += {forbidden_term}

    s <- strip_reference_phrases(t)              # mask interval-naming phrases
    for every direction d != E[code].direction:
        if any STATUS_WORDS[d] matches s:
            V += {contradictory_wording}; break

for code in E not in seen:
    V += {missing_analyte}

c <- strip_accents(O["closing"])
if any FORBIDDEN_PATTERN matches c:
    V += {forbidden_term, code=_closing}

if C.overall_label != normal:                    # only then can reassurance be false
    if any FALSE_REASSURANCE_PATTERN matches strip_reference_phrases(c):
        V += {false_reassurance}

return pass if V is empty else fail
```

### B.2 Normalisation before matching

`strip_accents` applies Unicode NFD, drops combining marks, maps `đ` to `d` and lower-cases the text, so `Thiếu máu` and `thieu mau` match the same pattern.

`strip_reference_phrases` replaces phrases that name the reference interval with the token `KHOANG_THAM_CHIEU` before any status word is matched. Without it, the correct sentence *cao hơn khoảng bình thường* (higher than the normal range) would match the pattern for *bình thường* and be reported as contradictory wording. A phrase is masked only when a comparator precedes it, matched by `(?:cao hon|thap hon|vuot|tren|duoi|ngoai|lech|so voi)`; a bare assertion such as *đang ở mức bình thường* carries no comparator and is therefore kept and judged.

Masking patterns:

```
(?:cao hon|thap hon|vuot|tren|duoi|ngoai|lech|so voi)\s+(?:khoang|muc|nguong|gioi han|tri so)?\s*binh thuong\b
\bkhoang tham chieu\b
```

### B.4 What the validator cannot see

The checks are lexical. Three limits follow, and all three are stated in Section 6.2 rather than left to the reader:

1. Indirect phrasing escapes the status words. A sentence that implies a value is fine without using any listed phrase passes.
2. The forbidden list enumerates patterns; a disease name outside it passes.
3. Agreement with a label is not correctness of the label. If Layer 2 is wrong, the whole pipeline is consistently wrong and the validator reports a pass.

For this reason the metric is reported as a validator-pass rate and not as safe output, and the paper reports that a deterministic template reaches the same rate.

### B.5 A false-positive mode we found and did not remove

Reviewer 1 asked for the validator's precision. We have no human-annotated set from which to estimate it, so we report what we can establish and label the rest as future work.

One systematic false positive is identifiable by inspection. The contradictory-wording check masks phrases that name the reference interval, but only when a comparator precedes them. A sentence that states the interval as a fact carries no comparator and so is judged as a status claim. An instance from the baseline log, panel SYN-0149:

> *Kết quả Plt là 0 10^9/L, đây là một kết quả rất thấp. Thường, mức Plt bình thường nằm trong khoảng 150–400 10^9/L.*

Layer 2 labelled the platelet count low, the model said low, and the second sentence merely quotes the interval. The check reports contradictory wording all the same. Scanning the 206 flagged sentences in the baseline log for this shape identifies 50 of them (24.3%) as candidates for the same mistake. The figure comes from a pattern scan and not from annotation, so it is an indication of magnitude rather than a precision estimate.

We left the behaviour in place for this paper, because changing the validator after seeing the results would invalidate the comparison between configurations that were already scored with it. The direction of the bias is worth stating: a validator that over-reports contradictions rejects outputs that were in fact acceptable, which inflates the fallback rate and therefore understates how much usable text the model produced. It does not inflate the pass rate. Establishing precision and recall against human-annotated statements, and then correcting the masking rule, is the first item of future work on Layer 4.
